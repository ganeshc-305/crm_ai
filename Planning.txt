Project Requirements Document

This is a project to showcase the AI Launchpad fresher training program in my company.
The topics to be used in the project are as follows:
1. RAG
2. Agentic AI
3. Multi-agents
4. Tool Calling
5. Function Calling
6. LangChain
7. Vector Database
8. Prompt Engineering
9. Embedding Models
10. LLM
11. Chat Context Memory
12. Chat History
13. Streamlit UI
14. MCP Server (Optional)

Tech Stacks to be used in the project are as follows:
1. Python
2. Streamlit
3. LangChain
4. OpenAI API
5. Vector Database (FAISS/ChromaDB)
6. MCP Server
7. Pydantic
8. PostgreSQL
9. GraphRAG (Optional)
10. LangGraph (Optional)
11. LangSmith (Optional)

Company Laptop Constraints:
1. Only Python and PostgreSQL are allowed to be installed on the company laptop.
2. Only company provided api key for llm and embedding models can be used with their base_url.
3. Only 100 api calls and 25mb of file upload size are allowed per week for the project.
4. The project should be completed within 5 days.
5. The IDE to be used for the project is VS Code.

Project Idea:
1. The project will be a web application that allows users to interact with an AI-powered assistant for CRM (Customer Relationship Management) tasks. The assistant will leverage RAG (Retrieval-Augmented Generation) to provide accurate and context-aware responses to user queries. Users can upload documents, and the assistant will use vector databases to retrieve relevant information and generate responses and use tool to insert the data into PostgreSQL database.

2. The application will feature a multi-agent system where different agents handle specific tasks such as document retrieval, query processing, and response generation. The agents will communicate with each other to ensure seamless interaction and efficient task completion.

3. The application will utilize tool calling and function calling to enhance the capabilities of the AI assistant. Users can invoke specific tools or functions to perform tasks such as data analysis, report generation, and more.

4. The application will be built using Streamlit for the user interface, allowing users to easily interact with the AI assistant through a web browser. The UI will include features such as chat context memory and chat history to provide a more personalized experience. The UI will also allow users to upload documents, view retrieved information, and interact with the AI assistant in a conversational manner. The UI is made with Apple HIG (Human Interface Guidelines) to ensure a user-friendly and visually appealing design.

5. The application will be deployed on an MCP server, ensuring that it is accessible to users within the company network. The server will handle requests from the Streamlit UI and manage interactions with the AI assistant, vector database, and other components of the system. (Optional)

6. The project will be developed using Python, leveraging libraries such as LangChain for building the multi-agent system, OpenAI API for LLM and embedding models, and a vector database (FAISS or ChromaDB) for efficient document retrieval. Pydantic will be used for data validation and management, while PostgreSQL will serve as the backend database for storing user data and chat history.

7. The project will also explore optional components such as GraphRAG, LangGraph, and LangSmith to enhance the capabilities of the AI assistant and provide additional features for users.

8. The project will be completed within the specified constraints, ensuring that it adheres to the company's policies and guidelines. The final deliverable will be a fully functional web application that showcases the capabilities of the AI Launchpad fresher training program and provides a valuable tool for CRM tasks within the company.

9. The project will include comprehensive documentation, including a user guide, technical specifications, and deployment instructions to facilitate future maintenance and enhancements.

10. A Supervisor Agent will be implemented to oversee the interactions between the different agents, ensuring that tasks are completed efficiently and that the system operates smoothly. The Supervisor Agent will monitor the performance of each agent, manage task assignments, and handle any errors or exceptions that may arise during operation.

11. Tool Calling and Function Calling will be implemented to allow users to invoke specific tools or functions within the application. This will enable users to perform tasks such as data analysis, report generation, and other CRM-related activities directly through the AI assistant.

12. Library Requirements will be managed using a requirements.txt file, ensuring that all necessary dependencies are installed and maintained throughout the development process. This will facilitate easy setup and deployment of the application on different environments.

13. The documents uploaded by users are Resume of the employees, SOW (Statement of Work), Previous Projects case study documents and other company-related documents. The AI assistant will process these documents to extract relevant information and provide context-aware responses to user queries.

14. The user will ask the AI assistant questions like "What is the SOW of Project X?" or "What are the key skills of Employee Y?" "Create a team for HSBC project and prepare a proposal draft" and the assistant will retrieve the relevant information from the uploaded documents and provide accurate responses.
